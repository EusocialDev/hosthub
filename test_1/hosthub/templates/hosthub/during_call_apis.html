During-call API catalog

This page is for API calls Bland makes while a guest is still on the phone. These calls are used by the AI in real time, so each entry should explain when Bland calls it, what variables it needs, what response it expects, and how the pathway should behave if the call fails.

Rule: keep this page focused on APIs Bland calls during the conversation. Final webhooks, dashboard actions, reports, and post-call automations belong in the main docs.

Catalog

Add new calls below this section. Keep one card per Bland tool/API call.

GET Location hours /test/api/hours/<location_slug>/ public used by Bland

Returns regular hours, future/current date overrides, and timezone for one active location. Bland can call this during a conversation when it needs current restaurant-hours context.

When Bland calls it
When a caller asks about hours, holiday hours, closures, or whether the restaurant is open.
Required pathway data
location_slug must match the HostHub Location.slug.
Authentication
Public endpoint. Do not include secrets in the request.
Failure behavior
If the slug is wrong or inactive, Bland should fall back gracefully instead of inventing hours.

Response shape

{
  "location": "160 Main",
  "timezone": "America/Detroit",
  "regular_hours": {
    "monday": {"closed": false, "open": "11:00", "close": "21:00"},
    "tuesday": {"closed": false, "open": "11:00", "close": "21:00"},
    "sunday": {"closed": true}
  },
  "date_overrides": [
    {
      "name": "Christmas Day",
      "start_date": "2026-12-25",
      "end_date": "2026-12-25",
      "closed": true
    }
  ]
}

Add A New During-Call API

To document a new Bland tool call, duplicate the template card below and replace the placeholder text. Keep the entry concrete enough that a developer can update the Django endpoint or Bland pathway without needing context from memory.

  1. Add one card per API call.
  2. Use the exact method and path Bland calls.
  3. List the pathway variables Bland must send or know before calling.
  4. Show request and response examples when useful.
  5. Document fallback behavior. During-call failures affect what the guest hears.
  6. Do not paste real secrets, webhook tokens, API keys, or private customer data.
