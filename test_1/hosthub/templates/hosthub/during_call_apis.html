During-call API catalog

This page is for API calls Bland makes while a guest is still on the phone. These calls are used by the AI in real time, so each entry should explain when Bland calls it, what variables it needs, what response it expects, and how the pathway should behave if the call fails.

Rule: keep this page focused on APIs Bland calls during the conversation. Final webhooks, dashboard actions, reports, and post-call automations belong in the main docs.

Hours of Operation

GET Location hours /test/api/hours/<location_slug>/ public HostHub

Returns regular hours, future/current date overrides, and timezone for one active location. Bland can call this during a conversation when it needs current restaurant-hours context.

Agents
Julia (Open) Julia (Closed)
Node Name
Q&A Node; Reservation
When Bland calls it
When a caller asks about hours, holiday hours, closures, or whether the restaurant is open.
Required pathway data
location_slug must match the HostHub Location.slug.
Authentication
Public endpoint. Do not include secrets in the request.
Failure behavior
If the slug is wrong or inactive, Bland should fall back gracefully instead of inventing hours.

Response shape

{
    "location": "160 Main",
    "timezone": "America/Detroit",
    "regular_hours": {
        "monday": {"closed": false, "open": "11:00", "close": "21:00"},
        "tuesday": {"closed": false, "open": "11:00", "close": "21:00"},
        "sunday": {"closed": true}
    },
    "date_overrides": [
        {
        "name": "Christmas Day",
        "start_date": "2026-12-25",
        "end_date": "2026-12-25",
        "closed": true
        }
    ]
}

GET Search Menu Item https://160maincarryout.com/api/agent/menu/search?q={{q}} protected 160maincarryout

Returns information about a menu item and its required modifiers. Bland can call this during the carryout order node when the user is placing an order. It uses RapidFuzz to search through different possible menu items and returns the best matches based on a scoring system.

Agents
Julia (Open)
Node Name
Carryout
When Bland calls it
When a caller is ordering an item.
Required pathway data
q item the user is trying to order. It can also be a comma-separated list of items.
Authentication
Protected endpoint. Bearer Token $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Token is wrong, it returns Unauthorized.

GET Menu Items Search https://160maincarryout.com/api/agent/menu/search?q={{q}} protected 160maincarryout

It searches through the menu based on the user's question. Unlike the other API endpoint that searches for the item the user is talking about to resolve modifiers, this endpoint looks for queries like gluten-free pasta and many other things that are not necessarily menu items but can be used to filter the menu and return a list of items that match the query.

Agents
Julia (Open)
Node Name
Carryout
When Bland calls it
When a caller is asking questions about the menu during the carryout node.
Required pathway data
menu_search_query query based on keywords from the user's question.
Authentication
Protected endpoint. Bearer Token $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Token is wrong, it returns Unauthorized.

POST Total Price Calculator https://160maincarryout.com/api/agent/order-summary/total protected 160maincarryout

It returns the total price based on the carryout website database. It takes a simple JSON body with a single key, order_summary, which is a string created by Bland for the full order. This string is semicolon-separated, for example: "1x Marsala; -Chicken; 2x Filet; - Medium;"

Agents
Julia (Open)
Node Name
Price Calculator (Webhook)
When Bland calls it
After the user shares the full order.
Required pathway data
order_summary variable with the user's full order quantities, items, and modifiers.
Authentication
Protected endpoint. Bearer Token $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Token is wrong, it returns Unauthorized.
If an item is not recognized, instead of having the whole call fail, the item appears in the warnings list in the response body.

Response shape

{
    "total_price": 134, 
    "warnings": []
}
POST 160Main Carryout https://hook.eu2.make.com/99ivo0o8ussulqe2m6rudrwqwt1n1ioy protected make.com

It is the API endpoint that finalizes a carryout order. It sends the order to the kitchen and host stand email, and sends an SMS confirmation to the user with the order summary and a Stripe payment link.

Agents
Julia (Open)
Node Name
Send Order to Host Stand
When Bland calls it
After the user confirms both phone number and name.
Required pathway data
order_summary variable with the user's full order quantities, items, and modifiers.
name variable with the user's name.
phone_number variable with the user's phone number.
total_price variable with the user's total price.
Authentication
Protected endpoint. Header x-make-apikey
Failure behavior
If the header protection token is wrong, it returns Unauthorized from Make.com.

Reservation

POST RESY Check https://resy-api-wrapper-production.up.railway.app/api/resy/availability/ protected RESY Wrapper

Returns a list with RESY availability based on date and party size.

Agents
Julia (Open) Julia (Closed)
Node Name
RESY Check Availability
When Bland calls it
After the agent gathers all the necessary information for a reservation.
Required pathway data
venue_id venue ID on RESY.
date date for the reservation.
party_size party size for the reservation.
requested_time requested time for the reservation.
tolerance_minutes window tolerance in minutes that determines the API-generated response for the agent. For example, if the user requested an 8:00pm reservation and there is availability inside that declared window, has_availability_45min_window will come back as true.
Authentication
Token Bearer $APP_ACCESS_PASSWORD
Failure behavior
It fails gracefully during the call. If the API returns an error, the agent does not mention the availability check.

Response shape

{
  "success": true,
  "data": {
    "available": true,
    "has_availability_45min_window": false,
    "available_times": [
      "16:00:00",
      "16:15:00",
      "16:30:00",
      "16:45:00",
      "17:00:00",
      "17:15:00",
      "17:45:00",
      "18:00:00",
      "18:15:00",
      "18:45:00",
      "19:00:00",
      "19:15:00",

POST 160Main Reservation https://resy-api-wrapper-production.up.railway.app/api/resy/availability/ public Make.com

Last step in the reservation flow. It sends reservation details to the host stand and manager. It also sends the user the reservation link from RESY so they can finalize their reservation.

Agents
Julia (Open) Julia (Closed)
Node Name
Reservation share with host/manager
When Bland calls it
After the agent gathers all the necessary information for a reservation or after the RESY availability check.
Required pathway data
user_name user's name for the reservation.
date date for the reservation.
time time for the reservation.
guests party size for the reservation.
short_from user's phone number for the reservation.
request any special request from the user.
Authentication
Token Bearer $APP_ACCESS_PASSWORD
Failure behavior
If any required fields are missing, it returns an error from Make.com.

Leave a Message

POST 160Main Leave a Message https://hook.eu2.make.com/ybpsab98c63yvgkecd4f35vieuh9qw8u public Make.com

For any requests that the AI agent is not capable of helping the user with, like real-time availability or other information it does not have, it prompts the user to say "Leave Message." It then sends the user to a global node where it understands the reason the user is contacting the restaurant, gets their contact information, and shares it with the host stand.

user_message a summarized message from the user about the reason for the contact.
Authentication
Public endpoint. Do not include secrets in the request.
Failure behavior
If any required fields are missing, it returns an error from Make.com.
