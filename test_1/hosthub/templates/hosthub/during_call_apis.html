During-call API catalog

This page is for API calls Bland makes while a guest is still on the phone. These calls are used by the AI in real time, so each entry should explain when Bland calls it, what variables it needs, what response it expects, and how the pathway should behave if the call fails.

Rule: keep this page focused on APIs Bland calls during the conversation. Final webhooks, dashboard actions, reports, and post-call automations belong in the main docs.

Hours of Operation

GET Location hours /test/api/hours/<location_slug>/ public HostHub

Returns regular hours, future/current date overrides, and timezone for one active location. Bland can call this during a conversation when it needs current restaurant-hours context.

Agents
Julia (Open) Julia (Closed)
Node Name
Q&A Node; Reservation
When Bland calls it
When a caller asks about hours, holiday hours, closures, or whether the restaurant is open.
Required pathway data
location_slug must match the HostHub Location.slug.
Authentication
Public endpoint. Do not include secrets in the request.
Failure behavior
If the slug is wrong or inactive, Bland should fall back gracefully instead of inventing hours.

Response shape

{
    "location": "160 Main",
    "timezone": "America/Detroit",
    "regular_hours": {
        "monday": {"closed": false, "open": "11:00", "close": "21:00"},
        "tuesday": {"closed": false, "open": "11:00", "close": "21:00"},
        "sunday": {"closed": true}
    },
    "date_overrides": [
        {
        "name": "Christmas Day",
        "start_date": "2026-12-25",
        "end_date": "2026-12-25",
        "closed": true
        }
    ]
}

GET Search Menu Item https://160maincarryout.com/api/agent/menu/search?q={{q}} protected 160maincarryout

Returns information about a menu item and its needed modifiers. Bland can call this during the carryout order node when user is placing an order. It uses rapidfuzz to search trhough different possible menu items and returns the best matches on a scoring system.

Agents
Julia (Open)
Node Name
Carryout
When Bland calls it
When a caller is ordering an item.
Required pathway data
q item user is trying to order, it can be a list of comma separated items
Authentication
Protected endpoint. Bearer Toeken $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Toeken is wrong it returns Unauthorized.

GET Menu Items Search https://160maincarryout.com/api/agent/menu/search?q={{q}} protected 160maincarryout

It searches trough the menu based on user question. Different than the other API endpoint that search the item user is talking about to resolve modifiers this endpoint looks for querries like gluten-free pasta and many other things that are not necessarily menu items but can be used to filter the menu and return a list of items that match the query.

Agents
Julia (Open)
Node Name
Carryout
When Bland calls it
When a caller is asking questions about the menu during the carryout node.
Required pathway data
menu_search_query query for search based on keywords from user question.
Authentication
Protected endpoint. Bearer Toeken $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Toeken is wrong it returns Unauthorized.

POST Menu Items Search https://160maincarryout.com/api/agent/order-summary/total protected 160maincarryout

It returns total price based on carryout website database. It takes a simple json body with a single key order_summary that is a sring created by Bland for the full order, this string is semicolen separated eg: "1x Marsala; -Chicken; 2X Filet; - Medium;"

Agents
Julia (Open)
Node Name
Price Caulculator (Webhook)
When Bland calls it
After user shared the full order
Required pathway data
order_summary Variable with user's full order quantities, items and modifiers.
Authentication
Protected endpoint. Bearer Toeken $VOICE_ORDER_API_TOKEN
Failure behavior
If the Bearer Toeken is wrong it returns Unauthorized.
If an item is not recognized, instead of having the whole call fail; the item appears on the warnings list on the body response.

Response shape

{
    "total_price": 134, 
    "warnings": []
}
POST Menu Items Search https://hook.eu2.make.com/99ivo0o8ussulqe2m6rudrwqwt1n1ioy protected make.com

It is the API endpoint that finalizes a carryout order. Sends order to the kitchen, to Host Stand Email, and SMS confimration to user with the order summary and a stripe payment link.

Agents
Julia (Open)
Node Name
Send Order to Host Stand
When Bland calls it
After user confrimed both phone number and name.
Required pathway data
order_summary Variable with user's full order quantities, items and modifiers.
name Variable with user's name.
phone_number Variable with user's phone number.
total_price Variable with user's total price.
Authentication
Protected endpoint. Header x-make-apikey
Failure behavior
If the header protcetion token is is wrong it returns Unauthorized from Make.com.
